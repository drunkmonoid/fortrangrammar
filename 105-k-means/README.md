# 105 — k-Means Clustering

One assignment step and one centroid update for 1-D k-means using pure integers.

## Behaviour

- Observations `0` and `10` are assigned to nearest initial centres `1` and `9` (`clusters: 1 2`).
- Centroid updates set the new centres to `0` and `10`.
